Where this page ends and OnAir begins

This page is the front door for Rivian Air Lines — the fleet, the base, the mission. The actual flying, bookings, and logbook all live inside OnAir Company itself.

The Live Company Stats panel above polls OnAir's public API directly from your browser using your own API key and Company ID, found in OnAir Desktop under Options.

Be aware: OnAir's API server may not allow direct browser requests from a page like this one (a CORS restriction, not a bug in your key). If the panel shows a connection error, that's almost certainly why — the fix is routing requests through a small server you control instead of straight from the browser, which I can help set up.
